# Bloomberg Index Solutions Limited (BISL)

Bloomberg Index Solutions Limited (BISL) administers Bloomberg's fixed income and multi-asset indices, including the Bloomberg Global Aggregate Bond Index. BISL provides index data, calculations, and licensing for asset managers and financial institutions.

## APIs

- **Bloomberg Index Data API** - Index constituent data, returns, and analytics
- **Bloomberg Index Licensing** - Licensing Bloomberg indices for financial products
